# DanielPashkevich.github.io

My portfolio website: https://danielpashkevich.github.io

## Editing

- **Your info** (name, bio, contact links, profile photo): edit `index.html`.
- **Projects**: edit `projects.js`. Each section has a list of projects with a title,
  a thumbnail (the square), the pictures shown in the pop-up, and a description.
- **Pictures**: put them in the `images` folder and use paths like `images/my-render.png`.
